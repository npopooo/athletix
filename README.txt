ATHLETIX - Personal Athletics Performance App

iPhoneで使う場合
1. GitHubリポジトリにこのフォルダ内のファイルをアップロードします。
2. GitHub Pagesを有効にし、公開された https://<username>.github.io/athletix/ をSafariで開きます。
3. Safariの共有ボタン →「ホーム画面に追加」でiPhoneのホーム画面に追加します。

主な機能
- 100m・走幅跳・三段跳などの目標管理
- 大会日から逆算するカウントダウン・週ごとの準備ロードマップ
- 大会記録、風速、メモの保存
- 食事・水分・疲労などのコンディション記録
- 2本の動画を並べて比較

注意
- 記録・目標・ログは利用中のブラウザ内（localStorage）に保存されます。別端末とは同期されず、ブラウザデータ削除で消える場合があります。
- 動画は端末内で一時プレビューするだけで、アップロード・クラウド保存はしません。
- 動画の骨格推定やAIによるフォーム診断、AIが個別に練習を処方する機能は未実装です。
- 大会逆算プランは大会日・種目・練習可能日数に応じた一般的な段階分けです。個別のトレーニング処方ではありません。実際の練習は指導者の方針、体調、疲労、痛みに合わせて調整してください。
- 公開リポジトリに個人情報や練習動画をアップロードしないでください。
